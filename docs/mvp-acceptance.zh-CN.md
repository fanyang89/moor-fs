# MVP 功能冻结与验收

## 冻结决定

- 用户已确认冻结功能，功能基线为 `13da45c`。
- 后续工作集中于验收、缺陷修复和上线必需的部署/运维文档。
- 新增功能、扩大恢复范围或改变架构需用户明确批准解冻；验收发现的新需求先记录，不自动实现。
- 当前是受控试运行候选，尚未认定生产可用。冻结不等于验收通过。

## 当前基线

原生 SMB 接入常驻 Zig 核心，通过内核 CIFS 访问两个独立 NAS；完整文件双副本、WAL 写入与恢复、完整性校验、密封基线、有限单文件恢复及显式重复控制临时文件回收已实现。

最近验证：Debug/Safe 各147项、真实 CIFS 挂载上的完整WAL故障回归通过。这里的CIFS测试使用回环Samba服务；SIGKILL结果不等价于物理NAS或硬件断电验收。各阶段原生SMB验证见设计文档，不能据此推定Windows/macOS兼容性已验收。

## 试运行边界

- 数据库和虚拟机工作负载不在范围内。
- 完整SMB共享模式、字节范围锁、持久ACL尚未完成，目标应用须单独验证。
- 整个副本目录丢失、data/WAL联合丢失、离线NAS重建及跨节点fencing/自动接管尚未实现。
- 全局操作锁与严格atime提交的性能影响待实测。
- 若试运行要求故障后自动持续服务，当前缺失能力构成阻塞；不通过扩大本轮功能范围隐式解决。

## 下一步

确定验收用物理NAS、客户端、目标应用、性能指标和测试数据范围，再开展验收。涉及清空数据、故障注入或断电的实际操作须获得对应目标与操作的明确授权。全部门槛完成后单独作出试运行或上线决定。
